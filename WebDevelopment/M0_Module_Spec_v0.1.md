## 1. 模块定位

M0 是整个“网页设计与制作”学习项目的入口模块。

本模块不以记忆大量网页史、标准组织或浏览器知识为目标，而是先建立一个足够清晰的最小心智模型：

> 一个网页项目是什么  
> → HTML / CSS / JavaScript 分别负责什么  
> → 浏览器如何读取这些文件  
> → 文件应该如何组织  
> → 如何在 VS Code 中创建、保存并运行一个最小网页

M0 完成后，应能无障碍进入 M1 的 HTML5 结构学习。

## 2. 目标深度

### 概念部分

目标：**L1 — 理解**

能够用自己的话解释：

- 网页与网站的大致关系；
- HTML、CSS、JavaScript 的职责区别；
- 浏览器在网页学习中的作用；
- 为什么网页通常由多个文件构成；
- 什么是 Web 标准的基本概念。

不要求：

- 研究浏览器内核；
- 深入 HTTP；
- 背诵 Web 标准历史；
- 掌握 JavaScript 编程。

### 操作部分

目标：**L2 — 能独立使用**

能够：

- 创建课程项目文件夹；
- 新建 `.html` 文件；
- 新建 `.css` 文件；
- 在 VS Code 中打开项目；
- 保存文件；
- 用浏览器打开 HTML；
- 刷新并观察修改；
- 判断常见“文件没保存 / 路径不对 / 浏览器没刷新”问题。

## 3. 必须建立的核心心智模型

### 3.1 网页不是“一张页面图片”

网页应理解为：

> 浏览器读取 HTML 等资源，并根据其中的结构、样式和行为规则生成最终页面。

不要形成：

> “网页就是 VS Code 里写出来的一张固定画面”

这种错误认知。

### 3.2 HTML / CSS / JavaScript 的基本分工

当前阶段使用最简单的三分法：

- **HTML：结构与内容**
- **CSS：表现与样式**
- **JavaScript：行为与交互**

这一分法是入门模型，不要求在 M0 讨论边界例外。

### 3.3 文件与浏览器结果的关系

必须理解：

> 代码文件本身 ≠ 浏览器最终显示结果

浏览器会解析 HTML、应用 CSS，并在需要时执行 JavaScript。

后续很多调试都建立在这个区分上。

## 5. 教学顺序

推荐按照以下顺序进行。

### Step 1 — 什么是网页

先建立：

- 网页；
- 网站；
- 浏览器；
- HTML 文件；

之间的关系。

安排 2–3 个极短判断题。

### Step 2 — HTML / CSS / JavaScript 分工

使用一个简单页面举例：

- 一段标题属于 HTML；
- 标题颜色属于 CSS；
- 点击按钮改变内容属于 JavaScript。

安排分类题。

### Step 3 — 浏览器做了什么

只讲工程级直觉：

> 读取 → 解析 → 组合 → 显示

不深入渲染引擎。

### Step 4 — 项目文件夹与文件

建立最小目录：

```text
my-first-web/
├─ index.html
└─ style.css
```

JavaScript 文件可以先知道存在：

```text
script.js
```

但不要求在 M0 编程。

### Step 5 — VS Code 最小操作

必须亲自完成：

- 打开文件夹；
- 新建文件；
- 输入；
- 保存；
- 在浏览器打开；
- 修改后刷新。

### Step 6 — 第一个网页

独立完成一个极简页面。

## 6. 必做练习

### Exercise 1 — 职责分类

给出若干任务，让学习者判断主要属于：

- HTML；
- CSS；
- JavaScript。

例如：

- 页面增加一个标题；
- 标题变成红色；
- 点击按钮后标题消失。

要求可使用极简答案。

---

### Exercise 2 — 文件识别

给出：

```text
project/
├─ index.html
├─ style.css
├─ script.js
└─ image/
   └─ logo.png
```

要求说明每个文件/目录大概承担什么。

---

### Exercise 3 — 最小网页

学习者亲自创建：

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>My First Web Page</title>
</head>
<body>
    <h1>我的第一个网页</h1>
    <p>这是我在网页设计与制作课程中创建的页面。</p>
</body>
</html>
```

本练习目的不是提前系统教学 HTML，而是让学习者完成：

> 文件 → 代码 → 保存 → 浏览器展示

这一整条链路。

教师应明确：

> HTML 结构细节会在 M1 正式展开，现在先把它视为可运行的最小样例。

---

### Exercise 4 — 修改并观察

要求修改：

- `<title>`；
- `<h1>` 内容；
- `<p>` 内容；

每改一项都：

1. 预测；
2. 保存；
3. 刷新；
4. 观察。

---

### Exercise 5 — 常见故障诊断

教师有意识制造至少 3 个简单故障：

- 文件没有保存；
- 打开错 HTML 文件；
- CSS 文件路径写错或尚未正确关联；
- 浏览器未刷新。

学习者先判断原因，再给提示。

## 7. M0 阶段小作业

### 任务

创建一个：

> “个人课程起始页”

页面至少包含：

- 网页标题；
- 一个一级标题；
- 两段文字；
- 一个简单列表；
- 一个本地图片（若当前已经会正确放置，可加入；否则可推迟到 M1）。

### 当前阶段重点

不是页面漂亮。

重点检查：

- 项目目录是否清楚；
- HTML 文件是否能正常打开；
- 内容是否正确显示；
- 学习者是否知道自己在修改哪个文件；
- 是否能解释 HTML / CSS / JavaScript 的分工。

## 9. 高频误区

教学中主动检查：

### 误区 1

> HTML 就是“网页编程语言”。

修正：

HTML 是标记语言，主要描述结构与内容。

### 误区 2

> CSS 是专门负责让网页“更好看”。

需要进一步补充：

CSS 不仅处理颜色等装饰，也控制尺寸、间距和布局。

### 误区 3

> JavaScript 是网页必需文件。

修正：

一个纯静态 HTML 页面可以没有 JavaScript。

### 误区 4

> VS Code 在运行网页。

修正：

VS Code 主要负责编辑；真正解析和展示页面的是浏览器。

### 误区 5

> 浏览器没变化 = 代码一定写错。

修正：

还可能是没保存、打开错文件、缓存/刷新、路径等问题。

## 10. Review 规则

M0 Review 重点按以下顺序：

1. 是否理解概念；
2. 文件操作是否正确；
3. 是否能建立运行链路；
4. 是否能自己发现简单错误；
5. HTML 细节只纠正影响运行和理解的部分。

不要在 M0 用大量 HTML 语法细节压垮入门目标。

---

## 11. 完成判据

M0 只有在学习者能做到以下内容时才完成：

### 必须满足

- 能解释 HTML / CSS / JavaScript 的基本分工；
- 知道浏览器负责解析和展示网页；
- 能使用 VS Code 创建并保存网页文件；
- 能从空文件夹建立最小网页项目；
- 能在浏览器中打开页面；
- 能通过修改代码观察页面变化；
- 遇到页面没变化时，知道至少检查“保存、文件、刷新”；
- 完成 M0 阶段小作业。

### 不要求

- 熟练 HTML；
- 熟练 CSS；
- JavaScript 编程；
- 完整网站制作。

---

## 12. M0 Completion Check

完成模块前进行一个极短闭卷检查。

### Part A — 概念

用一句话分别解释：

- HTML；
- CSS；
- JavaScript；
- 浏览器。

### Part B — 操作

从空文件夹开始建立：

```text
index.html
style.css
```

并成功在浏览器显示自己写的内容。

### Part C — 故障

教师给出一个“修改后浏览器没有变化”的场景，学习者至少提出三个可能检查点。

---

## 13. 完成后的移交

M0 完成后进入：

> **M1 — HTML5 基础与标签系统**

移交时记录：

- VS Code 操作是否熟练；
- 文件目录是否仍容易混淆；
- HTML / CSS / JavaScript 分工是否清楚；
- 是否存在“保存 / 刷新 / 路径”类高频错误；
- M0 小作业结果。

M1 不需要重复完整开发环境教学，只在出现真实操作问题时补充。
