若完整英文存在历史约定、现代含义与字面义不完全一致，应明确区分。

## 8. M2 核心心智模型

### 8.1 HTML 与 CSS 的职责分离

不断强化：

> HTML 描述“这是什么内容 / 结构”；  
> CSS 描述“这些内容如何表现”。

例如：

```html
<h1>课程标题</h1>
```

HTML 表达：

> 这是一级标题。

而：

```css
h1 {
    color: red;
}
```

CSS 表达：

> 被这个规则选中的一级标题文字显示为红色。

不要把：

> “h1 就是大字”  
> “CSS 只是加颜色”

作为长期心智模型。

---

### 8.2 CSS 规则 = 选谁 + 改什么

首次正式建立：

```css
h1 {
    color: red;
}
```

基本拆解：

```text
h1              → selector / 选择器
color           → property / 属性
red             → value / 值
color: red;     → declaration / 声明
{ ... }         → declaration block / 声明块
```

M2 期间持续强化：

> **选择器负责找到 HTML 元素；声明负责告诉浏览器如何表现这些元素。**

---

### 8.3 CSS 的“属性”与 HTML 属性不要混为同一层概念

HTML：

```html
<img src="a.png" alt="A">
```

这里 `src`、`alt` 是 HTML attributes。

CSS：

```css
img {
    width: 200px;
}
```

这里 `width` 是 CSS property。

中文都可能被教材称为“属性”，但技术角色不同。

教学时应明确：

> HTML attribute = HTML 属性 / 元素附加信息  
> CSS property = CSS 属性 / 样式规则中的表现维度

避免学习者因为中文同名而混淆。

## 9. 推荐教学顺序

### Step 1 — 极短恢复 M1 → M2 接口

只确认：

- HTML 页面能够正常运行；
- 外部 CSS 可以通过 `<link>` 接入；
- 相对路径仍然理解；
- 不重新教学完整 HTML。

---

### Step 2 — CSS 是什么

正式解释：

> CSS = Cascading Style Sheets

当前只重点理解：

- Style Sheets = 样式表；
- CSS 用于描述 HTML 的表现；
- “Cascading / 层叠”只先知道是名称的一部分和后续重要机制，详细规则留到 M3。

避免在 M2 一开始提前讲完整层叠算法。

---

### Step 3 — CSS 基本规则结构

重点学习：

```css
selector {
    property: value;
}
```

至少训练：

- 选择器；
- 花括号；
- 属性；
- 冒号；
- 属性值；
- 分号；
- 多条声明。

练习方式：

> 看规则 → 拆结构 → 预测效果 → 修改值 → 浏览器验证

---

### Step 4 — 三种 CSS 引入方式

依次认识：

#### 内联样式

```html
<h1 style="color: red;">标题</h1>
```

`style` = style，样式。

#### 内部样式

```html
<style>
    h1 {
        color: red;
    }
</style>
```

#### 外部样式

```html
<link rel="stylesheet" href="style.css">
```

要求理解：

- 三者分别写在哪里；
- CSS 是否仍然属于同一套语言；
- 为什么外部 CSS 更适合正常项目组织；
- 内联样式为什么不应成为默认写法。

M2 必须安排：

> 把一份内联样式重构成外部 CSS。

---

### Step 5 — 元素选择器

例如：

```css
h1 {
    color: red;
}
```

重点理解：

> 标签名作为选择器时，会选中匹配的同类元素。

需要通过多个 `h1 / p` 验证“批量命中”的效果。

---

### Step 6 — class 选择器

学习：

```html
<p class="note">...</p>
```

```css
.note {
    color: red;
}
```

解释：

- `class` = class，类别 / 类；
- HTML 中的 class 用于给一个或多个元素归入某类；
- CSS 中 `.note` 通过点号选择具有该 class 的元素。

重点建立：

> 多个元素可以共享同一个 class。

不要把 class 简单理解为“给元素起名字”。

---

### Step 7 — ID 选择器

学习：

```html
<h1 id="main-title">...</h1>
```

```css
#main-title {
    color: red;
}
```

解释：

- `id` = identifier，标识符；
- CSS 中 `#` 用于按 id 选择元素；
- 页面中的 id 应保持唯一性直觉。

M2 只训练基础使用。

不要提前系统展开 ID 与 class 的 specificity 差异；优先级属于 M3。

---

### Step 8 — 元素 / class / ID 的选择判断

通过情境判断：

> 我想选全部段落 → 元素选择器  
> 我想选若干“警告信息” → class  
> 我想标识一个特定唯一元素 → id

不要只做术语背诵，要让学习者根据真实页面需求选择。

---

### Step 9 — CSS 未生效的基础排查

M2 至少覆盖：

- HTML / CSS 是否保存；
- 浏览器是否刷新；
- `<link>` 是否存在；
- `href` 路径是否正确；
- CSS 文件名是否正确；
- 选择器是否选中了目标；
- 属性名 / 值是否拼写明显错误；
- 花括号 / 冒号 / 分号等基础语法是否破坏规则。

若问题涉及：

- 多条规则覆盖；
- specificity；
- inheritance；
- source order；

只做必要提示并标记：

> **M3 系统学习。**
