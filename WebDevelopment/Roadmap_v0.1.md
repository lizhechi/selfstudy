# Web Design and Production Learning Project — Roadmap v0.1

> 状态：Initial Roadmap  
> 版本：v0.1  
> 上位文件：`Anchor_v0.1.md`  
> 适用教材：《HTML5+CSS3 网页设计与制作（第2版）》  
> 性质：阶段规划文件  
> 作用：定义学习阶段、教材章节映射、模块顺序、目标深度、练习类型与完成判据。  
> 本文件不承担逐节完整讲义。

## 1. 总体路线

本课程采用：

> 浏览器与网页概念  
> → HTML 结构  
> → CSS 基础  
> → 选择器与层叠  
> → 盒模型  
> → 常见内容结构  
> → 表单  
> → 布局  
> → 多媒体与动效  
> → JavaScript / Canvas / Storage 入门  
> → 综合网站

教学过程中始终执行：

> 讲解 → 预测 → 最小实验 → 独立编写 → 浏览器验证 → Review → 修正 → 综合迁移

# 3. 每个模块的推荐教学单元

每个模块尽量采用 20–45 分钟的“小循环”，而不是一次讲完整章。

一个循环通常为：

1. 讲一个核心概念；
2. 给一个很小的例子；
3. 做 1–3 个预测 / 判断；
4. 学习者亲自写；
5. 在浏览器运行；
6. Review；
7. 进入下一个知识点。

只有在确实需要学习者输出时停下来等待。

# 4. 阶段性闭卷检查

每完成一个主要 Phase，应插入一个未直接见过的综合任务。

### HTML 阶段

从空白文件写一页结构正确的图文页面。

### CSS 阶段

给出 HTML，独立完成指定样式。

### 盒模型阶段

根据尺寸要求实现卡片，并解释最终宽高。

### 布局阶段

根据草图完成页面布局。

### 期末阶段

完成一个小型多页面网站并口头解释关键实现。

# 5. 与课堂进度同步规则

当学习者提供：

- 老师本周讲到的页码；
- PPT；
- 作业；
- 考试范围；
- 课堂截图；
- 代码；

应优先把 Roadmap 当前焦点移动到课堂附近。

允许：

> 课堂先学到第7章，而系统学习还在第4章。

此时采用“双进度”：

- **课堂跟进线**：保证当前作业和上课听懂；
- **基础补课线**：逐步补齐此前缺口。

不要求强行按照教材顺序等待。

---

# 6. 练习比例建议

对于第2–8章：

> 约 30% 讲解 + 50% 亲自写代码 + 20% Review / 调试

对于第9–11章：

> 约 40% 讲解 + 40% 小实验 + 20% Review

对于第12章：

> 以项目实践为主。

---

# 7. 当前建议起点

如果课堂尚未明显领先：

> M0 → M1 → M2 → M3 → M5

第4章复杂选择器可以与 CSS 基础交叉学习，不必在第一次接触 CSS 时一次全部学完。

如果课堂已经进入后面章节，应先保证：

> **M1（HTML）+ M2/M3（CSS基础）+ M5（盒模型）**

这四块没有明显空洞，再追课堂进度。

---

# 8. Roadmap 升级规则

以下情况应考虑升级：

- 老师公布考试范围并显著改变章节优先级；
- 课堂使用与教材不同的现代技术；
- 发现某章实际上是本课程大作业核心；
- 学习者在阶段测验中暴露稳定知识缺口；
- 课程进度与教材结构明显不一致。

单次练习难度调整不升级 Roadmap。
