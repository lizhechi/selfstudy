## 1. 模块定位

M1 是正式进入 HTML 学习的第一个核心模块。

M0 已建立：

> 项目文件夹 → HTML/CSS 文件 → VS Code 编辑 → 保存 → 浏览器读取 → 显示结果

M1 在此基础上进一步建立：

> HTML 文档结构是什么  
> → 标签 / 元素 / 属性是什么  
> → 内容如何被组织成结构  
> → 标签之间如何嵌套  
> → 常见基础标签如何独立使用  
> → 浏览器为什么会按不同结构显示内容  
> → 如何识别并修复常见 HTML 结构错误

M1 的目标不是背完所有 HTML 标签，而是建立一个稳定的“HTML 结构语言”心智模型，并能从空白文件独立搭建结构正确的静态页面。

---

## 2. 目标深度

M1 总体目标：**L3 — 能解释、调试和迁移**

学习者应逐步达到：

- 能从空白文件写出基本 HTML5 文档结构；
- 能解释常用标签在结构中的作用；
- 能区分标签、元素、属性；
- 能判断父子 / 兄弟 / 嵌套关系；
- 能使用常见文本、图像、链接等基础标签；
- 能处理基础资源路径；
- 能发现常见未闭合、错误嵌套、路径错误等问题；
- 能把一段无结构内容整理为合理 HTML；
- 能在简单新任务中选择基本合适的标签。

不要求：

- 背完全部 HTML5 标签；
- 系统学习 CSS；
- 系统学习布局；
- JavaScript；
- DOM；
- HTTP；
- 前端框架。

## 3. M1 核心心智模型

### 3.1 HTML 的核心不是“显示文字”

HTML 的职责是：

> **描述网页的内容与结构。**

同样是文字：

```html
<h1>课程标题</h1>
<p>课程介绍正文。</p>
```

不仅“显示不同”，还表达了：

- 哪部分是一级标题；
- 哪部分是段落；
- 内容之间是什么结构关系。

因此必须避免形成：

> “标签只是为了让浏览器显示不同样式”

这种错误认知。

---

### 3.2 标签、元素、属性必须区分

M1 需要建立三个基本概念：

#### 标签

如：

```html
<p>
</p>
```

#### 元素

如：

```html
<p>一段文字</p>
```

整体才是一个元素。

#### 属性

如：

```html
<img src="image/logo.png" alt="Logo">
```

其中 `src`、`alt` 是属性。

学习初期允许使用简化表达，但在 M1 收尾前应能基本区分。

---

### 3.3 HTML 是树状结构，不是“标签堆”

例如：

```html
<body>
    <h1>标题</h1>
    <p>正文</p>
</body>
```

应逐步形成：

```text
body
├─ h1
└─ p
```

这种结构直觉。

后续 CSS 选择器、布局、DOM 等内容都依赖这一基础。

---

### 3.4 显示结果与结构语义不同

例如：

```html
<p>123</p>
```

与：

```html
123
```

可能都能显示 `123`，但结构含义不同。

M1 要逐步建立：

> “浏览器能显示” ≠ “结构合理”。

## 5. 教学顺序

### Step 1 — 回顾 M0 链路

只做极短复习：

- HTML / CSS / JavaScript 分工；
- VS Code 与浏览器职责；
- HTML 引用 CSS；
- 保存 / 刷新 / 路径。

不重复完整 M0。

---

### Step 2 — HTML5 文档骨架

正式拆解：

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>页面标题</title>
</head>
<body>
</body>
</html>
```

目标不是一次全部背会，而是理解：

- 哪些属于文档骨架；
- `<head>` 与 `<body>` 分别放什么；
- `<title>` 与正文标题不同；
- `meta charset` 为什么存在。

---

### Step 3 — 标签 / 元素 / 属性

用极小例子反复区分。

安排：

- 判断；
- 指认；
- 修改；
- 找错。

---

### Step 4 — 文本结构标签

逐步学习：

- `<h1>`–`<h6>`；
- `<p>`；
- `<br>`；
- `<hr>`；
- 常见文本标签。

重点不是背样式，而是：

> 每个标签表达什么结构角色。

---

### Step 5 — 嵌套与关系

建立：

- 父元素；
- 子元素；
- 兄弟元素；
- 正确嵌套；
- 闭合关系。

通过小型 HTML 树训练。

---

### Step 6 — HTML 实体

理解：

- 为什么某些字符不能直接按普通文本理解；
- 常见实体的基本用途。

不要求大量背诵。

---

### Step 7 — 图像与资源路径

学习：

```html
<img src="..." alt="...">
```

重点：

- `src`；
- `alt`；
- 相对路径；
- 文件夹层级；
- 路径错误诊断。

---

### Step 8 — 结构化小页面

把一段无结构文字整理为：

- 标题；
- 段落；
- 列表 / 图片（若教材进度已覆盖）；
- 合理层级。

---

### Step 9 — 综合排错

至少覆盖：

- 未闭合；
- 错误嵌套；
- 标签名拼写错误；
- 路径错误；
- 文件名错误；
- 把显示结果误当结构语义。

---

## 6. 记忆巩固机制

鉴于学习者已明确反馈：

> 刚学过的语法会较快模糊，单次讲解不足以形成稳定记忆。

M1 不采用：

> “讲过一次 → 默认已经记住”

的推进方式。

改为：

> 初见 → 看提示使用 → 半提示回忆 → 极简闭卷回忆 → 后续任务重复出现

### 6.1 三层提示制度

#### Level A — 完整参考

首次出现时允许看到完整语法。

#### Level B — 关键词提示

例如只提示：

> “段落标签是 p”

由学习者自行补全。

#### Level C — 无提示回忆

在已经多次使用后再做。

不得在第一次或第二次接触后就把“闭卷默写失败”视为未掌握。

---

### 6.2 高频复现优先于死记

核心标签通过后续任务不断重复。

例如 `<p>`、`<h1>`、`<img>` 应在多个练习中自然复现，而不是单独布置大量机械抄写。

---

### 6.3 错误回测

若某项错误反复出现，应在 1–3 个教学单元后重新测试。

重点记录：

- 文档骨架遗忘；
- 标签未闭合；
- 错误嵌套；
- `<head>` / `<body>` 混淆；
- 文件名 / 页面标题混淆；
- 路径错误；
- `<br>` 被滥用为布局间距；
- 把标签默认外观当作标签本质。

---

## 7. 必做练习

### Exercise 1 — 文档骨架识别

给出完整 HTML，要求指出：

- 文档声明；
- html；
- head；
- body；
- title。

---

### Exercise 2 — 标签 / 元素 / 属性分类

例如：

```html
<img src="image/a.png" alt="A">
```

要求指出：

- 标签；
- 元素；
- 属性。

---

### Exercise 3 — 结构语义判断

给出不同写法，判断：

- 哪个是标题；
- 哪个是段落；
- 哪个只是普通文本；
- 哪些写法虽然能显示但结构不合理。

---

### Exercise 4 — 嵌套找错

例如提供 3–5 行短代码，让学习者找：

- 错误闭合；
- 交叉嵌套；
- 漏标签。

---

### Exercise 5 — 路径实验

给出：

```text
project/
├─ index.html
└─ image/
   └─ logo.png
```

让学习者写出正确 `src`，并故意制造一次路径错误。

---

### Exercise 6 — 从文字到结构

给出：

> 网页标题  
> 一段简介  
> 第二段说明  
> 一个图片说明

要求选择合理标签组织。

## 8. M1 阶段小作业

### 任务

完成一个：

> **个人学习介绍页**

至少包含：

- 正确 HTML5 文档骨架；
- 浏览器页面标题；
- 一级标题；
- 至少两个不同层级标题或结构区分；
- 至少 3 个段落；
- 一张本地图片；
- 至少一个简单列表（若教材已覆盖）；
- 基本合理的标签嵌套；
- 清晰项目目录。

CSS 可以存在，但不作为 M1 核心评分项。

### 验收重点

- 结构是否合理；
- 标签是否选得基本合适；
- 是否理解标签角色；
- 是否有明显嵌套错误；
- 图片路径是否正确；
- 是否能解释自己的结构。

---

## 10. Review 规则

M1 Review 按以下优先级：

1. HTML 结构是否成立；
2. 标签是否表达合理结构语义；
3. 嵌套是否正确；
4. 路径是否正确；
5. 属性是否正确；
6. 格式与缩进；
7. 页面是否“好看”。

不要把 CSS 美观程度作为 M1 主评价指标。

---

## 11. 完成判据

M1 完成时，学习者应能：

- 理解并基本独立写出 HTML5 文档结构；
- 区分标签、元素、属性；
- 理解 `<head>` 与 `<body>`；
- 正确使用常见标题与段落标签；
- 理解标签嵌套与父子 / 兄弟关系；
- 插入本地图片并处理基础相对路径；
- 发现常见未闭合 / 错误嵌套 / 路径错误；
- 把一段简单无结构内容整理为合理 HTML；
- 在参考逐渐减少的情况下完成一个小型静态页面。

## 12. M1 Completion Check

### Part A — 概念

用自己的话解释：

- 标签；
- 元素；
- 属性；
- head；
- body；
- HTML 为什么不只是“让文字显示出来”。

### Part B — 结构

给出一段短 HTML：

- 判断父子 / 兄弟；
- 找出嵌套问题；
- 判断结构是否合理。

### Part C — 操作

从空文件夹建立一个 HTML 页面。

允许按记忆巩固机制分级：

- 首次可使用关键词提示；
- 若多次练习后稳定，可尝试闭卷。

不要求仅凭记忆完整默写所有低频标签。

### Part D — 路径

给定目录结构，正确引用一张本地图片，并能解释路径为什么这样写。

## 13. 完成后的移交

M1 完成后进入：

> **M2 — CSS 规则、引入方式与基础选择器**

移交时记录：

- HTML5 文档骨架是否稳定；
- 标签 / 元素 / 属性是否仍混淆；
- 嵌套错误是否高频；
- 路径理解是否稳定；
- 哪些标签仍需提示；
- 是否存在过度使用 `<br>` 等问题；
- M1 小作业结果；
- 需要在 M2 中继续复现的 HTML 弱项。

---

## 14. M1 与记忆要求的边界

M1 的目标不是：

> “把所有语法背下来以后才能进入 M2”。

而是：

> 高频语法逐步进入长期记忆，低频语法知道存在并能查；  
> 核心结构必须能解释、能使用、能调试。

只有会显著阻碍后续 CSS 学习的 HTML 缺口，才需要在 M1 收尾前补强。
